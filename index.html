Networking

The fabric follows from the node count. East-west carries GPU-to-GPU traffic, north-south carries client and storage traffic; both default to non-blocking, and each plane can run on Ethernet or InfiniBand. An NVIDIA reference architecture fixes all of this and sizes the fabric by its own rules.

Platform

Every server in the solution, configurable on processor, memory and disk. Each build starts as its reference architecture specifies it and is checked against the specification NVIDIA publishes for that role; power, weight, the rack elevations and the bill of materials follow whatever you change.
